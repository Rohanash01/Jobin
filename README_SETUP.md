## 🖼️ Important: Add Your Photo

The website expects a photo file named `artist.jpg` in the root directory. 

**To add your photo:**
1. Place your photo file as `artist.jpg` in `/workspaces/Jobin/`
2. Supported formats: JPG, JPEG, PNG
3. Recommended size: 600x700px (portrait orientation)
4. The photo will automatically display in the hero section
